A short text written to leave its reader braver: steadier, unhurried, ready to move. `main.py` writes it to `/output/entry.txt` — a night watchman, a small lamp, and the next step, in 245 characters. The text shows courage rather than instructing it: no imperatives, no stock wellness phrases, sentences that shorten toward the end so the reading itself slows down. Draft candidates and the pick rationale are in `BUILD-NOTES.md`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
